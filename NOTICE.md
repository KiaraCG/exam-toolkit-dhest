# Source and redistribution notice

This package is a documented adaptation of standalone exam-scoring scripts supplied for this task, with newly written generic configuration, demonstration, provenance and packaging components. It is not presented as an official release of an institution's platform, EthelFlow or EthelExam.

The supplied standalone source files did not include an explicit license declaration establishing redistribution terms for this assembled package. No institutional ownership or software license has been invented here. The responsible rights holder should confirm and attach the intended license before a public software release. This notice is not a substitute for that decision.

Third-party dependencies are installed through their normal package repositories and retain their own licenses. Their library source, binaries and font files are not bundled. The synthetic fixture PDFs use standard PDF fonts and do not ship separate font programs.

The package excludes real student submissions, real grading outputs, source examination PDFs and working credentials. The source files and tests remain subject to local review and a controlled deployment pilot. See `docs/REFERENCES.md` for retained mechanisms and newly added behavior, and `docs/SECURITY_AND_SHARING.md` for distribution controls and their limits.
