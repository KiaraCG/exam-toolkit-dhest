# Illustrative policy fragments, not an active exam

`items.json` illustrates complete manifest-entry syntax for common numerical policies. These entries do not define a full rubric or a ready-to-run exam. They carry invented display names and notes. Add the appropriate question statements, criteria and approved reference content before using any policy in a real profile.

A binary two-point MC item, a nonuniform four-point set, half-point increments and continuous fractional credit can coexist. A positive maximum does not by itself choose a policy. The follow-through example also needs the referenced earlier criterion in the final manifest; a dependency does not automatically award any points.

There is no universal default for AR/KR, additive versus result-only credit, penalty reuse, permitted fallback data or MC authority. Write the instructor-approved meaning in words. Negative marking and conditional/best-of totals require an explicitly versioned extension of the current nonnegative scoring contract.
